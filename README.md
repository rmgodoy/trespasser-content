# Trespasser System Assets

This document tracks the alchemical, martial, and mystical assets created for the Trespasser system.

## Content
### Character
- **Callings**: Cleric, Diabolist, Invoker, Knight, Magician, Marauder, Thief, and Warrior.
- **Crafts**: Comprehensive deed lists for major disciplines:
  - Battle, Blood, Brawling, Command, Curses, Defense, Earth, Flames, Frost, Gloom, Grace, Hunting, Illusion, Prowess, Radiance, Storm, Treachery, Wild, Wind, and Wrath.
- **Past Lives**: Artisans, Fallen Nobility, Farmers, Laborers, Merchants, Outcasts, Servants, and Soldiers.
- **Possessions**: Standardized starting gear packages linked to each Past Life.

### Items & Gear
- **Weapons**: Crude weapons (Melee and Missile) with integrated states (Bleeding, Slow, Burning, etc.).
- **Armor**: Crude armor sets including Head, Body, Arms, Legs, Outer, and Shields with Armor Ratings and Depletion Dice.
- **Adventuring Tools**: 60+ items including Alchemy Sets, Camping Gear, Light Sources (Lanterns, Torches), Animals, and General Supplies.
- **Concotions**: 
  - **Potions**: Consumption effects like Healing, Strength, and Invigoration.
  - **Powders**: External alchemical dusts.
  - **Oils**: Weapon coatings for elemental and debuff effects.
  - **Bombs**: Alchemical explosives with area damage and terrain effects.

### Deeds
- **Deeds**: All Crafts's Deeds.
- **States**: 
  - **Standard States**: Accurate, Afflicted, Blinded, Bleeding, Burning, Frail, Fortified, Guarded, Hastened, Inaccurate, Mending, Slow, Strong, Toppled, Unguarded, Weak, Willful.
  - **Special States**: Custom mechanics like Admonishment, Aegis of Air, and Alter Fate.
  - **Deed's States**: Custom effects confered by the deeds.

### Magic
- **Incantations**: A library of mystical spells with endurance costs and spark-able effects.

## Instalation

1. Use the manifest URL to install the module in Foundry VTT (https://raw.githubusercontent.com/rmgodoy/trespasser-content/main/module.json).
2. Enable the module in your world.
3. Import all content (IMPORTANT to enable KEEP DOCUMENT ID). This step is important to allow the items to reference each other using the UUID. Callings, Crafts, Features, Talents, Deeds and other, all uses reference through UUID to be able to interact with the actor sheets.
